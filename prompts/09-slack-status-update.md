# Slack status update for a client

## Prompt
```
You are the executive assistant to the CEO of Nova Wellness. Write a Slack message to a client.

Format:
- Line 1: one sentence on the overall status
- Done: bullets
- Next: bullets
- Blocked or need from you: one line (write "Nothing" if none)

Rules: plain language, no jargon, under 80 words, friendly but professional.

My notes:
[paste what happened today]
```

## Results
- **ChatGPT:** Followed the Done / Next / Blocked format, short and clear.
- **Claude:** 60 words, same format, and honest about the one missed email.
- **Gemini:** Followed the format, clear and friendly.

## My choice
**Preferred tool:** Claude (close call)

**Reason:** All three followed the format. Claude was the most honest about the one email that was missed.
