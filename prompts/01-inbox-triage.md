# Inbox triage

## Prompt
```
Act as an executive assistant at Nova Wellness. This is a fictional exercise. Use only the information below and answer directly in this chat without accessing connected apps.

It is Tuesday at 9 am. These five emails are in my inbox:

1. A client has a meeting with our CEO at 10 am today but hasn't received the meeting link.
2. A venue will release our provisional workshop booking unless we confirm by noon today.
3. Finance has sent an invoice that is due on Friday.
4. A candidate has asked for interview time options for next week and needs a reply by tomorrow.
5. A supplier has sent a monthly newsletter with no action requested.

Sort these emails in the order I should handle them. Present a table with: email number, priority (High, Medium or Low), reason, next action and deadline.

Use clear actions, such as "Send the client the meeting link." If a deadline isn't given, write "Not specified." Recommend actions only; don't carry them out.
```

## Results
All three tools ranked the emails in the same order (1, 2, 4, 3, 5).

- **ChatGPT:** Used the five requested columns. Added an unrequested "Recommended approach" paragraph.
- **Claude:** Added an extra Order column. Added a note about the budget that came from outside the prompt.
- **Gemini:** Used exactly the five requested columns and added nothing extra.

## My choice
**Preferred tool:** Gemini

**Reason:** Used exactly the five columns I asked for and added nothing extra. Claude added an Order column and a note about the budget that came from outside the prompt, even though I said to use only the information given. ChatGPT added an unrequested "Recommended approach" paragraph.
